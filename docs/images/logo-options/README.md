# Diagramble logo concepts

[Process in Motion](logo-1.svg) uses a process circle and two bent arrows to show data entering and leaving a step. Deep teal lines and a pale cyan circle sit beside a blue-gray wordmark on an ice-blue plate.

[Shared Source](logo-2.svg) branches from a single model into a process circle, an entity box, and dictionary lines. Violet shapes and a deep plum wordmark sit on a lavender plate.

[Rule Fitted](logo-3.svg) closes an open entity frame with a check mark to show a model satisfying an explicit rule. A leaf-green check pairs with a forest-green frame and wordmark on a mint plate.

[Connected D](logo-4.svg) draws the initial as a loop with three diagram nodes, tying the name to the act of connecting parts of a system. Copper nodes and a dark brown wordmark sit on a pale apricot plate.

[Model in Words](logo-5.svg) puts dictionary rows inside a speech bubble to capture how Diagramble explains model problems in plain language. Berry linework, a rose fill, and a burgundy wordmark sit on a blush plate.
